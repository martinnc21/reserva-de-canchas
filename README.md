# Reserva de Canchas

Aplicación web para consultar canchas deportivas, ver sus horarios disponibles y simular una reserva.

## Funcionalidades

- Listado de canchas con deporte, superficie, precio e imagen.
- Búsqueda por nombre o deporte.
- Vista de detalle de cada cancha.
- Horarios disponibles y confirmación simulada de reserva.

## Tecnologías

- React
- TypeScript y JSX
- Vite
- CSS

## Ejecución local

Necesitas tener Node.js y npm instalados.

```bash
npm install
npm run dev
```

Abre en el navegador la dirección local que muestre Vite en la terminal.

Para comprobar que compila:

```bash
npm run build
```
